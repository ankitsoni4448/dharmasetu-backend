# Panchang reference requirements

Engineering cases are prepared for Datia, Gwalior, Delhi, Varanasi, Mumbai, and Bengaluru across normal days, UTC/India date boundaries, Ekadashi, Purnima, Amavasya, and major festivals.

Each case requires independently trusted values for weekday, Tithi, Nakshatra, Yoga, Karana, sunrise, sunset, and festival/vrat status. Until supplied and reviewed, results are `REFERENCE_DATA_REQUIRED`; DharmaSetu output is never its own reference.
